# Anthony Apollis — Cape Town LinkedIn campaign

17 September 2026. A fresh campaign for the live project and availability for remote roles, freelance and contract projects.

Open index.html to browse the four visuals, copy the post and short article, and find the tag guide.

- Three portrait posters: 1122 × 1402 PNG, approximately 4:5.
- One landscape article cover: 1774 × 887 PNG, 2:1.
- A ready-to-paste LinkedIn post and a variant with suggested GIS mentions.
- A short article, relevant profile/page links, hashtag sets, captions and alt text.
- generation-prompts.json: the exact four prompts used with the built-in image-generation tool.

Suggested use: upload posters 01–03 together in that order with the main post. For a single image, use poster 01. Use image 04 as the article cover, with the supplied short article. Choose one of the contextual mention lines and select the actual profiles in LinkedIn’s mention picker before posting.

The skills copy describes this portfolio’s implemented work. The Power BI claim is semantic modelling and DAX, not a deployed production dashboard. All artwork is conceptual and AI-generated. No outreach or LinkedIn publishing has been performed.
